# 儒藏本体论 · Confucian Canon Ontology

全藏智能知识图谱与义理推演平台，参考[易经本体论](https://yejinlei.github.io/The-Book-of-Changes/)构建，收录殆知阁儒藏908部典籍、1.39亿字文献。

## 功能模块

- **首页**：本体七层架构、五常定德、四书五经、三纲八目、义理流派、历代圣贤、义理工具、核心原典
- **古籍全文库**：908部典籍按分类浏览，支持书名搜索，点击进入阅读页
- **阅读页**：概念自动标注、字号切换、竖排/横排切换、概念弹窗释义
- **本体七层**：从L0元模型层到L6文化外延层的完整本体架构说明
- **义理图谱**：ECharts交互式力导向图，展示概念、经典、人物、学派之间的关联
- **儒学词典**：70+核心儒学概念释义，附经典出处
- **儒门道脉**：从孔子到戴震的2500年儒学传承时间轴
- **流派对比**：程朱理学、陆王心学、汉唐经学、清代朴学四大流派对比
- **义理推演**：基于BFS的概念路径智能推演，演示儒家修养次第

## 部署方式

### GitHub Pages
1. 将整个目录所有文件上传到GitHub仓库main分支根目录
2. 仓库Settings → Pages → Source选main分支/(root) → Save
3. 等待1-2分钟即可访问

### 本地预览
```bash
cd rucang-new
python3 -m http.server 8000
# 访问 http://localhost:8000
```
